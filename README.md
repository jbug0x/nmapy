# nmapy

Reimplementação simplificada do nmap em Python, feita para fins de estudo de cybersecurity (varredura de portas, descoberta de hosts, etc).

> ⚠️ Projeto educacional. Use apenas em redes/hosts que você tem autorização para testar.

## Status

🚧 Em desenvolvimento.

## Objetivo

Explorar conceitos de scanning de rede (TCP connect scan, SYN scan, detecção de hosts ativos, banner grabbing) implementando versões simplificadas em Python puro / com bibliotecas como `scapy` e `socket`.
